# Лабораторні роботи з веброзробки

Один репозиторій містить усі лабораторні. Відкривайте у VS Code саме папку
`lab_WEB`, а не окрему лабораторну.

## Структура

- `index.html` — головна сторінка зі списком робіт.
- `frontend-lab-1/lab1.html` — сторінка першої лабораторної з навігацією.
- `lab_2/lab2.html` — сторінка другої лабораторної з навігацією.
- `lab3/lab3.html`–`lab10/lab10.html` — сторінки наступних лабораторних.
- `assets/styles.css` — спільний дизайн портфоліо; класи мають префікс `portal-`.
- `assets/script.js` — автоматична висота вбудованих робіт при запуску через сервер.
- У `frontend-lab-1/` і `lab_2/` збережені початкові `index.html` та їхні стилі.
- У перших двох папках `portal.css` і `portal.js` відповідають за сторінку
  з навігацією; у папках `lab3`–`lab10` це `styles.css` і `script.js`.
- Роботи 3–10 поки мають сторінки-заготовки з повідомленням «Ще не додано».

Перші дві роботи показуються через `iframe`: CSS кожної роботи залишається
в окремому документі та не конфліктує з портфоліо. Посилання «Відкрити окремо»
відкриває оригінал у новій вкладці. Хедер і навігація портфоліо залишаються
на зовнішній сторінці. Навіть без JavaScript усі посилання та роботи доступні;
вбудована робота за потреби має власне прокручування.

У кожної роботи власні `index.html`, `styles.css`, за потреби `script.js` та
`images/`. Підключайте їх відносними шляхами: `./styles.css`, `./images/photo.jpg`.
Не створюйте `.git` у папках лабораторних і не запускайте в них `git init`.

## Нова лабораторна

1. Відкрийте потрібну заготовку, наприклад `lab3/lab3.html`.
2. Замініть секцію `.portal-empty` вмістом роботи або вбудованим документом
   за зразком `lab_2/lab2.html`. Для ізоляції стилів зберігайте саму роботу
   в окремому документі, наприклад `lab3/index.html`.
3. Оновіть тему роботи на головній та заголовок її сторінки. Посилання вже створене.
4. Перевірте сторінку через Live Preview у VS Code або відкрийте HTML у браузері.
5. У GitHub Desktop перегляньте зміни, створіть commit і натисніть Push origin.

## GitHub Desktop

Додавайте через **File → Add local repository** цю папку:

```text
C:\Users\hp\source\repos\lab_WEB
```

Усі лабораторні з’являються в одному списку змін. Віддалений репозиторій:
`https://github.com/Splothy/lab_WEB.git`.

## GitHub Pages

У репозиторії GitHub відкрийте **Settings → Pages**:

- Source: **Deploy from a branch**.
- Branch: **main**.
- Folder: **/ (root)**.
- Натисніть **Save**.

Після push та успішного розгортання адреси будуть такими:

- Головна: https://splothy.github.io/lab_WEB/
- ЛР №1: https://splothy.github.io/lab_WEB/frontend-lab-1/lab1.html
- ЛР №2: https://splothy.github.io/lab_WEB/lab_2/lab2.html
- Решта: `lab3/lab3.html`–`lab10/lab10.html` за тим самим принципом.

Викладачеві надсилайте пряму адресу потрібної лабораторної.
Регістр назв файлів та папок у посиланнях має збігатися з реальними назвами.

## Резервні копії Git

Під час об’єднання вкладеного репозиторію його службові дані та резервні копії
історії збережені локально у `.git-backups/`. Ця папка виключена з Git і не
публікується. Робочі файли першої лабораторної залишаються у `frontend-lab-1/`.
