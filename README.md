# Лабораторні роботи з веброзробки

Ковальчук Ярослав Олегович · КН-311

## Структура

- `index.html` — головна з посиланнями на 10 лабораторних.
- `assets/styles.css` — оформлення головної.
- `assets/header.css` — спільні змінні, фон і стилі навігації.
- `assets/header.js` — створює хедер головної або іконку дому в лабораторних.
- `assets/placeholder.css` — спільний мінімальний стиль ще не виконаних робіт.
- `frontend-lab-1/index.html` — перша робота; `about.html` — її окрема змістова сторінка.
- `lab_2/index.html` — друга робота.
- `lab3/index.html`–`lab10/index.html` — заготовки наступних робіт.

Кожна лабораторна відкривається безпосередньо в тій самій вкладці. Немає iframe,
сторінок-обгорток чи кнопки відкриття повноекранної версії.
У папці роботи зберігайте її HTML, `styles.css` та `script.js`, якщо потрібна логіка.
Порожні JavaScript-файли не створюємо.

## Спільна навігація

У `<head>` кожної лабораторної після її власного CSS підключіть:

```html
<link rel="stylesheet" href="../assets/header.css" />
<script src="../assets/header.js" defer></script>
```

Додайте `class="lab-page"` до `body`. Це застосує спільний фон і відступ 48 px
зліва для іконки дому. Власний хедер лабораторної залишається незалежним.
Усі стилі спільної навігації мають префікс `shared-`, змінні — `--portal-`.
Розмітку хедера копіювати не потрібно. Для головної використовується `data-home`.
JavaScript потрібен лише для вставлення спільної навігації; вміст робіт — звичайний HTML.

## Робота над лабораторною

1. Відкрийте всю папку `lab_WEB` у VS Code.
2. Редагуйте `index.html` та `styles.css` у потрібній папці.
3. Для нової роботи замініть заготовку власною розміткою і стилями.
4. Перевірте головну та роботу через Live Server або відкрийте HTML у браузері.
5. У GitHub Desktop перегляньте зміни, створіть commit і натисніть Push origin.

Не запускайте `git init` у папках лабораторних: для всіх робіт є один репозиторій.
