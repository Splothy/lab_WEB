# Лабораторні роботи з веброзробки

Один репозиторій містить усі лабораторні. Відкривайте у VS Code саме папку
`lab_WEB`, а не окрему лабораторну.

## Структура

- `index.html` — головна сторінка зі списком робіт.
- `assets/styles.css` — стилі тільки головної сторінки.
- `frontend-lab-1/` — лабораторна №1.
- `lab_2/` — лабораторна №2.
- `lab_3/`, `lab_4/` тощо — папки для наступних робіт, коли вони з’являться.

У кожної роботи власні `index.html`, `styles.css`, за потреби `script.js` та
`images/`. Підключайте їх відносними шляхами: `./styles.css`, `./images/photo.jpg`.
Не створюйте `.git` у папках лабораторних і не запускайте в них `git init`.

## Нова лабораторна

1. Створіть папку, наприклад `lab_3`.
2. Додайте в неї `index.html` і `styles.css`.
3. Додайте посилання `./lab_3/` до списку в кореневому `index.html`.
4. Перевірте сторінку через Live Preview у VS Code або відкрийте HTML у браузері.
5. У GitHub Desktop перегляньте зміни, створіть commit і натисніть Push origin.

## GitHub Desktop

Додавайте через **File → Add local repository** цю папку:

```text
C:\Users\hp\source\repos\lab_WEB
```

Усі лабораторні з’являються в одному списку змін. Віддалений репозиторій:
`https://github.com/Splothy/lab_WEB.git`.

## GitHub Pages

У репозиторії GitHub відкрийте **Settings → Pages**:

- Source: **Deploy from a branch**.
- Branch: **main**.
- Folder: **/ (root)**.
- Натисніть **Save**.

Після push та успішного розгортання адреси будуть такими:

- Головна: https://splothy.github.io/lab_WEB/
- ЛР №1: https://splothy.github.io/lab_WEB/frontend-lab-1/
- ЛР №2: https://splothy.github.io/lab_WEB/lab_2/

Викладачеві надсилайте пряму адресу потрібної лабораторної.
Регістр назв файлів та папок у посиланнях має збігатися з реальними назвами.

## Резервні копії Git

Під час об’єднання вкладеного репозиторію його службові дані та резервні копії
історії збережені локально у `.git-backups/`. Ця папка виключена з Git і не
публікується. Робочі файли першої лабораторної залишаються у `frontend-lab-1/`.
